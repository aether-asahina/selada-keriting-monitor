Keamanan Sistem: Perlindungan Pompa Kering & Timeout

Sistem menerapkan pengamanan berlapis:

  • Batas Durasi Maksimal (Timeout): Pompa dibatasi menyala kontinu maksimal 120 detik untuk mencegah over-irrigation bila sensor tercabut.
  • Deadband Histeresis (65% – 78%): Mencegah osilasi relay sakelar frekuensi tinggi (chattering) yang merusak kontak mekanis relay.
  • Pemisahan Status SCADA: Status permintaan perangkat lunak (pumpCommand) tidak pernah disamakan dengan sakelar fisik (relayActual) tanpa verifikasi sinyal feedback ESP32.

Alur Kerja Sistem IoT

ESP32 Sensor WiFi, tiap 1s → Firebase RTDB HTTP Poll → Dashboard Selada
ESP32-CAM HTTP LAN, port 81 → Dashboard Selada

Data telemetri sensor ditransmisikan melalui Firebase RTDB secara global, sedangkan feed video kamera ESP32-CAM disajikan melalui jaringan lokal WiFi yang sama.

Langkah Pemasangan & Kalibrasi

  1. Nyalakan ESP32 Sensor: Bila belum terkoneksi, LCD menampilkan info AP esp selada keriting.
  2. Hubungkan ke AP: Buka 192.168.4.1 via browser, pilih WiFi Anda, dan simpan kredensial.
  3. Cek Transmisi Data: Setelah tersambung, LCD menampilkan alamat IP dan telemetri otomatis terkirim ke Firebase setiap 1 detik.
  4. Nyalakan ESP32-CAM: Sambungkan ke WiFi ESP32-CAM-SELADA, atur WiFi yang sama, dan catat alamat IP yang didapatkan.
  5. Buka Tab Kamera: Masukkan alamat IP ESP32-CAM di tab Kamera lalu klik tombol "Hubungkan".

Pemecahan Masalah (Troubleshooting)

Data sensor tidak muncul atau tertunda

Pastikan ESP32 tersambung ke WiFi dan LCD menampilkan IP lokal. Gunakan tombol "Uji Koneksi" pada tab Pengaturan untuk memastikan endpoint Firebase dapat diakses.

Status "Perangkat offline" muncul

Muncul jika tidak ada data baru yang masuk melebihi batas waktu aturan offline (default 15 detik). Periksa catu daya ESP32 dan koneksi WiFi router.

Suhu atau kelembapan udara DHT22 tidak berubah

Program hanya memperbarui nilai bila sensor DHT22 berhasil dibaca. Jika gagal, pembacaan terakhir tetap dikirim. Periksa koneksi pin data GPIO 13.

Pompa terus menyala atau tidak merespons

Irigasi beroperasi berdasarkan batas histeresis (menyala <65%, mati >78%). Pastikan relay aktif LOW terpasang di GPIO 26 dan sensor tanah terkalibrasi.

Video ESP32-CAM tidak tampil di browser

ESP32-CAM hanya mendukung 1 client stream aktif secara bersamaan. Pastikan tab lain tidak sedang membuka feed, dan gunakan mode HTTP bukan HTTPS jika ada pemblokiran mixed-content.

Konfirmasi Perintah Pompa / Relay SCADA

Anda akan mengirim perubahan setpoint perintah pompa irigasi (GPIO 26 Aktif-LOW). Pastikan media tanam dan instalasi pipa siap sebelum mengeksekusi perintah.

Catatan Keamanan Hardware

Perintah kontroler (pumpCommand) tetap tunduk pada batas proteksi timeout 120 detik dan verifikasi feedback fisik (relayActual) dari ESP32 Kelompok 5.
